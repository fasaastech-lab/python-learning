# Git Commit Message Rules

## The 7 Rules
1. Separate subject from body with blank line
2. Limit subject line to 50 characters
3. Capitalize the subject line
4. Do not end with a period
5. Use imperative mood
6. Wrap body at 72 characters
7. Use body to explain what and why not how

## Imperative Mood
Write as if giving a command.

## Common Verbs
Add     - Adding new files or features
Fix     - Fixing bugs
Update  - Updating existing code
Remove  - Deleting files or code
Build   - Creating a project
Rebuild - Rewriting with improvements
Rename  - Renaming files
Clean   - Cleaning up code

## Examples
"Add Python exercises for chapters 1 to 6"
"Fix top student bug in grade book"
"Rebuild prayer tracker using dictionaries"
"Remove duplicate exercise files"
